# Era 1: the table web, 1996–2003

Build a page that passes as a commercial site from about 1998–2001, or one of its survivors (Hacker News, Drudge, Berkshire Hathaway).

Marks: **(V)** seen in a real archived capture; **(U)** unverified. **[artifact]** = artifact mode only; costume mode drops or replaces it as stated.

## 1. The failure to beat

The commonest failure is a page that is too clean, too complete and too designed. Real pages were either minimal and hand-made, or machine-generated and sloppy; never tidy and thorough at once. When unsure, cut a section rather than add one.

## 2. Shared rules

### Document and head

- No doctype (V: Yahoo 1998, Amazon 1999, MapQuest 2000, Hotmail 2001, CDnow 1999). The page renders in quirks mode. Artifact: none. Costume: optional; none is period, and adding one changes the gaps around images in table cells, so check the screenshot.
- Minimal `<head>`: `<title>` and maybe `<base>`. If a meta appears, it is a stuffed keywords list (~600–700 chars, Amazon and MapQuest) or a PICS-Label (MapQuest).
- Declare UTF-8 the period way: `<meta http-equiv="Content-Type" content="text/html; charset=utf-8">`. Not `<meta charset>`.
- Title = brand plus slogan, with odd punctuation: `Amazon.com--Earth's Biggest Selection`, `Yahoo!`.
- `<body>` bare or with only `bgcolor text link vlink alink`. Colours often lack `#` (Excite: `bgcolor="FFFFFF" link="000066"`). No margin attributes: the browser's 8px margin shows.

### Markup

- Lay out with `<table>`: nested tables, `cellpadding`/`cellspacing`, `width=` in px or `100%`. Spacer GIFs (`blank_1x1.gif`, `s.gif`, `width=10 height=1`) set gaps.
- Wrap nearly every run of text in its own `<font face="verdana,arial,helvetica" size=-1>` (sometimes `geneva,arial`). Sizes `-1`, `-2`, `1`, `2`. Repeat per cell; never set the font once at the top.
- Style in attributes: `bgcolor`, `<font>`, `<center>`, `align`, `valign`. CSS, if any, is a thin layer on top: Hotmail `<font class="f">`, MapQuest a tiny inline `<style>` tinting `.button`, MonoBook one sheet with `* html` hacks.
- `<hr>` is rare, mostly before the footer: Excite `<hr noshade size=1 width=98%>`. (Drudge, with ~40, is the exception.)
- Hand-written pages use upper/mixed-case tags with unquoted attributes (U).
- [artifact] Imperfect markup: broken quoting (`face="verdana," arial`), typos (`helvectica`, `<met ...>`), empty `<tr></tr>` and `<td> </td>`, a missing `</tr>`, `<form>` directly inside `<table>`, `<a name="#top">`. A few, not so many they look deliberate. Costume: keep empty cells and `<form>` in a table (they render fine); drop typos and broken quoting.

### Type

- Small Verdana/Arial: ~10pt body (`size=-1` ≈ 13px), ~7pt metadata (`size=1` ≈ 10px).
- No type scale. Emphasis is `<b>` or `size=+N`: MapQuest bold `size=4` links, Drudge a `size=+7` red headline.
- Headings, where styled, are plain with a 1px rule beneath (MonoBook H1).

### Links and images

- Text is in GIFs: logos, tab labels, even Hotmail's language picker (312×65 with a map). Make them with `make_assets.py logo` and `navmap`: hard-edged (no antialiasing), a system serif (old business, newspaper) or Verdana/Arial bold, cropped tight with no blank strip.
- Navigation is ONE wide GIF with `usemap` (often also `ismap`); the `<map>`/`<area>` block sits at the end of the file. Yahoo 460×59, Amazon 590×59, MapQuest polygon areas. Not one image per button.
- Small functional images only: product covers in blurbs (`align=left hspace=7 vspace=3`, Amazon 78×107), logos, bullet GIFs, compass GIFs.
- Bullets vary by site: `<li>` (Yahoo), a literal `•` (Amazon, Excite), a tiny GIF (MapQuest yellow triangle).
- [artifact] Images by absolute URL from a separate image host (`us.yimg.com`, `mqgraphics.mapquest.com/gif/`, a bare IP), some without `alt`. Costume: relative paths (or your own `img.` subdomain over HTTPS) and `alt` on every image.
- [artifact] Session and tracking IDs in URLs and hidden inputs: `uid=u55a02t7b4uclbxe:...`, `/exec/obidos/.../ref=gw_m_r_bo_1/`, `SID=...`, `/cgi-bin/...?link=...`. Costume: plain URLs.

### Navigation

- Text links separated by `|` or `-`, top and footer; "more..." in bold.
- Directory lists: a `<ul><li>` list in two table columns, each item `<a><b>Category</b></a><font size=-1><br>sub, sub, sub...</font><br><br>` (Yahoo). Amazon does the same in its left rail without `<ul>`.
- Boxed tabs with 1px borders, selected one tinted (MonoBook).
- A "Text Only" version link (Amazon).

### Copy and content

- The homepage IS the content: an index of links, or the tool itself. Dozens of links per screen (~90 on Amazon's home, hundreds on Drudge).
- Literal, specific copy: titles, authors, dates, counts, prices. Cross-promo one-liners ("Yahoo! Mail - free email account"). Proof is the content (bestseller lists, shareholder letters), not logos or testimonials.
- Date top-right in small type: "Wednesday, October 13, 1999", "Updated Hourly". Small grey metadata under items (date, author, points).
- Footer: a `Text | Text | Text` link row, then one line in the smallest size: "© 1996-1999, Amazon.com, Inc.", "Legal Notices", "TERMS OF USE / Privacy Statement". Yahoo has no © line, just region lists in a table. [artifact] a stale year; costume: end the range at the current year.

### Forms and JavaScript

- Native controls sized in characters: Yahoo `size=30` + "Search"; MapQuest `size=15` and a 2-char state box. Buttons named for the action: "Get Directions" / "Clear".
- Every action is a full page load; state lives in the URL and hidden inputs.
- JS is peripheral and the page works without it: `window.open(...,'width=515,height=600')` help pop-ups, `form.login.focus()`, an `onchange` that swaps the form action. No motion; hover barely styled.

## 3. Genres

### Portal / directory (Yahoo 1998, Excite 1999)
White page, logo GIF top-left with the image-map nav GIF beside or under it, a search box `size=30`, then the category directory in two columns (pattern above). No boxed panels on Yahoo. Region lists in the footer table. Two `<hr>` at most.

### Store / catalogue (Amazon 1999, CDnow 1999)
- Amazon: `width=100%` page, 171px left rail of category links, content, 200px right rail. Boxes = a table in a 1px coloured table: outer `cellpadding=1 bgcolor=#cccc99`, inner `cellpadding=4` on white. Home page is editorial with no prices: three titles and authors per box, covers in blurbs, "100 Hot Books".
- CDnow: 590–600px column, prices shown. Use this width for a small local store or catalogue (no right rail): "List Price $17.97", red "Add to Cart $12.58" link, "Always 30% Off".

### Utility / tool (MapQuest 2000, Hotmail 2001)
The homepage is the tool. MapQuest: 739px table, grey form column, yellow/maroon, inline `.button` style, compass GIFs, a "Help" pop-up. Hotmail: blue brand panel, sign-in box, "New user? Sign up now!". No feature list, no funnel.

### Plain survivor: headlines, letters, link list (HN, Drudge, Berkshire)
Content top-left with the default margin. HN: `min-width` 796px table, `#f6f6ef`, orange bar, spacer GIFs, grey metadata lines. Drudge: columns of headline links, hundreds per page, ~40 `<hr>`, one huge red headline (`size=+7`). Berkshire: a list of links each with "Updated <date>", no images, purple/red links.

### Reference / wiki (Wikipedia MonoBook, 2005 CSS; late for this era)
One stylesheet, boxed 1px tabs with the selected one tinted, plain H1 with a 1px rule, `* html` IE hacks. Use for docs or a knowledge base that should feel early-2000s.

### Novelty / event (Space Jam 1996)
Commit fully: black page, tiled star GIF, red text, a ~500px layout of image links.

### Personal homepage (GeoCities, Angelfire): not checked (U)
Hit counters, "best viewed in" badges, under-construction GIFs and webrings were absent on 10+ commercial captures. Use them only for an explicitly personal/hobby page, and say they are unverified.

## 4. Costume mode: phones and basics

- **Phones:** keep the fixed table. Add `<meta name="viewport" content="width=W">`, W = the layout width + 16 (a 100% layout uses 800). It is invisible on desktop and makes the phone open fitted to the table instead of a 980px canvas. Never disable zoom (`user-scalable=no`, `maximum-scale=1`): readers pinch-zoom, as they did. Keep the main text at `size=-1` or larger so it survives the zoom-out; keep tap targets as the period's padded table cells. Leave iOS text inflation on.
- **Basics stay, without changing the look:** `alt` on every image (`alt=""` on spacers; image-map `<area alt>` carry the labels), `<label>` around each control's text, a text link row beside any image-map nav (Amazon had one), readable contrast, HTTPS, UTF-8.
- **Drop:** session/tracking IDs, `http://` assets, separate image hosts you don't own, typos and broken quoting, stale ©, ad `document.write`.

## 5. Tells (self-check)

A convincing era-1 page has most of these:
- no doctype; `<font>` on nearly every text run; the layout is tables with spacer GIFs;
- an image-map nav GIF or `|`-separated text links; small Verdana at `size=-1`;
- a house palette with set link/vlink colours; one loud accent;
- the homepage is the content or the tool; dozens of literal links; a date or "Updated" stamp;
- a two-line footer (`Text | Text`, then a tiny © line).

## 6. Avoid

- **Too new:** any doctype, CSS layout (floats, flex, grid), `border-radius`, shadows, CSS gradients, `rgba`, `@font-face`, web fonts, `@media`, a `device-width` viewport, HTML5 elements, `data-` and `placeholder` attributes, `<svg>`, CSS transitions, ES6+ JS, and a meta description [artifact; costume may keep one for search].
- **Too modern in shape:** hero → feature cards → testimonials → pricing → FAQ; "NEW!" badges, countdowns, feature grids; buttons as the main affordance; generous uniform whitespace.
- **The cartoon:** "Best viewed in…", hit counters, under-construction GIFs, webrings, `<marquee>`/`<blink>` on a commercial page; boxes on a page that had none.
- **Too tidy:** `alt` on every image and consistent indentation [artifact only]; a single font declaration; class-based styling throughout.

## 8. Skeleton

A store page in costume mode; other genres keep the head and change the table. Repeat `<font>` in every cell.

```html
<html>
<head>
<title>Kessler &amp; Sons--Hardware Since 1952</title>
<meta http-equiv="Content-Type" content="text/html; charset=utf-8">
<meta name="viewport" content="width=616">
</head>
<body bgcolor="FFFFFF" text="000000" link="003399" vlink="996633" alink="FF9933">
<table width=600 cellpadding=0 cellspacing=0 border=0>
<tr><td><img src="images/logo.gif" width=174 height=21 alt="Kessler &amp; Sons"></td>
    <td align=right valign=bottom><font face="verdana,geneva,arial" size=1>Wednesday, October 13, 1999</font></td></tr>
<tr><td colspan=2><!-- navmap output: <img usemap> here, its <map> at the end of the file --></td></tr>
</table>
<table width=600 cellpadding=0 cellspacing=0 border=0><tr>
<td width=150 valign=top bgcolor="#cccc99"><font face="verdana,geneva,arial" size=-1><b>Departments</b><br>...</font></td>
<td width=10><img src="images/s.gif" width=10 height=1 alt=""></td>
<td width=440 valign=top><font face="verdana,geneva,arial" size=-1>...</font></td>
</tr></table>
<br><font face="verdana,geneva,arial" size=-1><a href="index.html">Home</a> | <a href="tools.html">Tools</a> | ...</font>
<br><font face="verdana,geneva,arial" size=1>&copy; 1952-2026 Kessler &amp; Sons Hardware</font>
<map name="nav">...</map>
</body>
</html>
```
