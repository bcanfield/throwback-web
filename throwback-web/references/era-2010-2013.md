## 1. The two failures

1. **The cartoon.** Three test builds overdid the skeuomorphic vocabulary:
   - a rendered iPhone with bezel and glare, where real pages used a flat screenshot with a drop shadow (Day One, Fantastical, Reeder, Clear);
   - gradient chrome on the nav, buttons and inputs of a shadowed sheet, where Elliot Jay Stocks put the texture behind the page and kept content flat, and Marco is flat;
   - the full `-moz-`/`-webkit-`/`-o-`/`filter` ladder on every button, where real CSS is patchy;
   - Lobster headings; a Like and a Tweet button on every post.

   Linen, stitching and ribbons were unseen in 11 real pages. One literal motif per site at most (Instagram paper clips; Gowalla leather).
2. **Too tidy, too stock.** The builds used one clean stack: Bootstrap 2.3.2 `.hero-unit`, 3-up, quotes, pricing, CTA; generic `#wrapper`/`#sidebar`; a clean head; hand-tidy CSS. Real pages had minified or inline CSS with a `*{margin:0;border:0;background:0}` reset, typos (`antialising`), commented-out rules; re-skinned Bootstrap (Mailgun airmail stripes and `stamp.png`; Balanced's 42 `@font-face` rules); CMS class names (`.odd_posts`, `.hentry`); heads with leftover metas and scripts. App-page nav, buttons and cards were bitmap sprites.

## 2. Shared rules

### Head

- **Doctype splits by genre, not year** (read in a browser):
  - App pages: HTML5 (Sparrow Apr 2012, Reeder Nov 2011, Fantastical Dec 2011, Clear Mar 2012); XHTML 1.0 Strict (Things Mar 2012, Tapbots Jul 2011); HTML 4.01 Transitional `loose.dtd` (Day One Feb 2012; Instagram Feb 2012 with http-equiv Content-Type, title `instagr.am`); none/quirks (Path Feb 2012, despite `<meta charset>` and a viewport). Lean HTML5; let one in three be older.
  - Startups: HTML5 on 4 of 4 (Mailgun lowercase `<!doctype html>`; Sentry; DrinkableTap; Balanced `<!DOCTYPE HTML>`, source only).
  - Blogs: self-built or WordPress 3.2+ (Twenty Eleven) → HTML5; WordPress 3.0-era theme or Tumblr's own page → XHTML 1.0 Transitional.
- **Viewport** mostly absent: Sentry, Mailgun, Balanced had none (Sentry 940px scrolls at 375px). Bootstrap templates, Path, Bootstrap 2.3.2: `width=device-width, initial-scale=1.0`. Bootstrap 2.0.0 example: none. Dribbble: `width=1000` (V-map). Sparrow: only `@media (max-device-width: 768px){ body{zoom:90%} }`.
- **Head clutter is normal:** `class="no-js"`, `X-UA-Compatible`, `dns-prefetch`, schema.org `itemscope`, Modernizr, Typekit (Clear); `author` and `copyright` metas (Day One); on old WordPress sites `imagetoolbar`, `revisit-after`, `distribution`, `robots`, keywords metas. `apple-touch-icon-precomposed` (57/72/114/144), Open Graph tags (V-map).

### Markup

- HTML5 sectioning appears in 2012 (`<header>`, `<nav role="navigation">`, `<article>`, `<footer role="contentinfo">`, Sparrow) but divs stay common: `#wrapper`, `#page`, `#shadow`, `#navi`, `#sidebar` (Things). Use the CMS's class names where there is a CMS.
- Image replacement everywhere:
  ```css
  .replace{display:block;overflow:hidden;text-indent:-999em;background:url(sprite.png) no-repeat}
  ```
  Logos, App Store buttons and nav are text-indented sprites (Sparrow).
- App pages: buttons and chrome are bitmaps (Coda `<img src="img/nav-download.png" onmouseover="fadeOut(this)">`; Fantastical nav slices 91/92px and `container-top-sides.png`; Clear `app-store-button.png` 206×73). CSS3 buttons are for forms and secondary actions.

### CSS

- **Untidy and often minified or inline:** Fantastical `master.css` minified; Reeder and Day One inline. A `*{margin:0;border:0;background:0}` reset, `/* DEFINITIONS */` headers with VERSION dates, commented-out blocks, `!important`.
- **Width:** centred fixed column: Sparrow 954, Bootstrap 2 `.container` 940, Clear 940, Gowalla 960 (V-map), MailChimp 960/990 (V-map), Instagram 810, Fantastical 804, Day One 630, Marco 620. Twenty Eleven fluid to 1000px. News sites fluid (Globe breakpoints 480/620/810/1400).
- **Prefixed, unevenly.** Sparrow's ladder:
  ```css
  -moz-border-radius:3px; -webkit-border-radius:3px; border-radius:3px;
  -webkit-box-shadow:0 1px 1px #fff; box-shadow:0 1px 1px #fff;
  background:-webkit-linear-gradient(top,#fff,#e0e0e0);
  background:-moz-linear-gradient(top,#fff,#e0e0e0);
  background:-o-linear-gradient(top,#fff,#e0e0e0);
  ```
  Bootstrap 2 `.btn` is the long form (to `filter: progid:DXImageTransform` and `*background-color`); Gowalla mixes `-webkit-gradient(linear, 0% 0%, 0% 100%, color-stop(...))` with `linear-gradient` (V-map). Most sheets are patchy: Clear bare `border-radius`, `-moz-`/`-webkit-` shadows, one `90deg` `-moz` gradient; Fantastical no `-o-`; Reeder has `-o-`; Elliot Jay Stocks radius `-webkit-`/`-moz-` only; Marco no CSS3 at all. Vary the prefix set per rule.
- **Radius small:** 3px (Sparrow), 4px (Bootstrap navbar, EJS images), 5px (MailChimp), 6px (hero unit, Tumblr button). No pills everywhere.
- **Letterpress, not universal:** dark text on grey gets `text-shadow:0 1px 1px #fff` (Sparrow); EJS puts `1px -1px 1px rgba(255,255,255,.6)` on all of `body`; Marco none; Twenty Eleven one in 2,670 lines. On dark fills the shadow goes up: `0 -1px 0 rgba(0,0,0,.25)` (Bootstrap `.btn-primary`). Hero text on a photo: `0 2px 1px rgba(0,0,0,.6)`. MailChimp edge pair `box-shadow:0px 1px 0 #373731, 0px -1px 0 #0e0d0b` (V-map).
- **Textures are bitmaps at the page edge:** Sparrow body `#e6e6e6 url(bg-noise.gif)` with a `#main` paper sheet `box-shadow:0 0 2px #666`; Fantastical/Reeder faint grey noise PNGs; Day One blue noise; Clear a blurred café photo; Shawn Blanc a repeating `background.jpg` on header, nav, footer; EJS a fixed paper `body.jpg` over a `repeat-x` `html.gif`; Gowalla `leather.jpg`, MailChimp `noise.png` (V-map). Marco and Twenty Eleven none. One texture, at the edge.
- **Responsive is an add-on or absent:** `bootstrap-responsive.css`; Globe `respond.min.js` + `@media screen and (min-width: 480px)`; Marco breakpoints 680/520.

### Type

- Helvetica Neue 13px/18px (Path, Bootstrap 2.0–2.2); 15px weight 300 (Twenty Eleven); Lucida Grande or Verdana 12px (Things, Tapbots); Day One 11px `"arial"`; Georgia on blogs and news (Marco 16px).
- Web fonts are Typekit, not Google Fonts or Cufón: Sparrow `proxima-nova-1, proxima-nova-2` (+ `.wf-active` bumping weights to 600); Fantastical and Clear `ff-dax-web-pro`; EJS `ff-tisa-web-pro-1, ff-tisa-web-pro-2, Georgia, Times`; Shawn Blanc `gesta`, `proxima-nova`, `warnock-pro`. Novelty heading faces existed (Gowalla Chalkduster, V-map). Google Fonts in this era's mainstream: U.

### JavaScript

- jQuery 1.x (Sparrow 1.7.1; Day One 1.4 with Fancybox 1.3.4). Small plugins: `jquery.easing.1.3`, `jquery.tweet`, `jquery.transit`, a carousel. Nivo Slider and Cufón (U).
- Social is sparse: Sparrow one Facebook Like iframe (`120×20`) in the footer + `addthis` CSS; Globe and EJS `plusone.js`; Marco an Instapaper "Read Later" iframe; Twenty Eleven none.
- [artifact] async `_gaq`, Mixpanel, Optimizely, Chartbeat. Costume: drop them.

## 3. Genres

### (a) iOS/Mac app marketing page (Sparrow, Things, Instagram, Tapbots, Coda, Reeder, Day One, Fantastical, Clear)

- **Layout:** a centred sheet 630–954px on a textured body. Reeder: 40/60 split on noise PNGs, CSS in page. Fantastical: 804px column, sprite nav, `container-top-sides.png`. Day One: 630px sheet on blue noise. Clear: 940px column over a full-width blurred photo.
- **Sparrow (Apr 2012) template:** 954px header, logo sprite, right-floated nav; a 345px `#featured` band (`#16356C`, tiled image, white 28px h1 with `0 2px 1px rgba(0,0,0,.6)`), screenshot at `bottom:0; right:69px` and kept inside the band.
- **Hero:** one product shot, one sentence: "Get mail done"; "Task management has never been this easy."; "Meet your new assistant."
- **Download buttons are bitmaps:** Sparrow 196×56 sprites, hover at `-170px`; Things stacks three tall buttons ("Download Things 1.5.4 / Mac OS X 10.6 or later", "Purchase … $49.95", "Now available on the Mac App Store"); Clear 206×73.
- **Product shot: a flat screenshot with a drop shadow, no bezel** (Day One, Fantastical, Reeder, Clear). Instagram is the exception: a 281px iPhone image left, a free badge at `top:20px; left:-35px`, a 509px right column with tab background and paper clips over brown `#563c13` text.
- **Features:** three 48px sprite icons, 17px h2, 14px grey text (Sparrow); Things a two-column list of 16 small PNG icons; Fantastical a list with "Coming Soon" items, a press-kit link, a newsletter box.
- **Proof:** press quotes as logo sprites that swap the quote text (Sparrow); awards in a sidebar (Things); a design-award badge (Coda).
- **Footer short:** a 10px `<small>` "© 2011 Company"; a logo and © (costume: the current year); `Contact | Impressum`.
- **Assets:** a logo + nav sprite in the header; the download button from `make_assets.py appbutton` (normal over hover) in the hero or download strip; feature icons from `sprite`, using its printed rules; the product shot pasted into `window` (flat frame, baked shadow). No corner GIFs.

### (b) Bootstrap-2-era startup or SaaS page

- **Pin the version to the date:** 2012 pages had 13px/18px body → Bootstrap 2.0–2.2. 2.3.2 (14px/20px, Mar 2013) is a 2013 look. Bootstrap was often folded into a site sheet (`ba-bs.css`, `mg.css`).
- **Real startups rarely used `.hero-unit`.** Sentry and Mailgun wrote their own `header`/`#header` and used only grid classes (`span4 feature`, `span5 offset1`, `span9`, `span10`). The stock template is for a Bootstrap-showcase page only:
  ```html
  <div class="navbar navbar-fixed-top"><div class="navbar-inner"><div class="container">
    <a class="btn btn-navbar" data-toggle="collapse" data-target=".nav-collapse">3 × <span class="i-bar"></span> (2.0; icon-bar later)</a>
    <a class="brand" href="#">Project name</a>
    <div class="nav-collapse"><ul class="nav"><li class="active"><a href="#">Home</a></li>...
  <div class="hero-unit"><h1>...</h1><p>...</p><p><a class="btn btn-primary btn-large">Learn more &raquo;</a></p></div>
  <div class="row"><div class="span4"><h2>...</h2><p>...</p><p><a class="btn" href="#">View details &raquo;</a></p></div> ×3
  <hr><footer><p>&copy; Company 2012</p></footer>
  ```
  `<!DOCTYPE html>`, `<meta charset="utf-8">`, "Le styles" comments, html5shim conditional, apple-touch icons, `body{padding-top:60px}`. Hero unit `padding:60px; background:#eee; border-radius:6px; font-weight:200`; `.btn-primary` `#0088cc→#0055cc` (2.0) / `#0044cc` (2.3); `.span4` 300px of 940. Glyphicons PNG sprites (`icon-*`).
- **Skin it heavily:** Mailgun (Dec 2012) airmail-stripe borders, `paper.png`, `stamp.png`, `barcode.png`, 16-column grid, rendered devices; Balanced 42 `@font-face` rules; Sentry a real dashboard screenshot on a flat `#f04618` hero with Pictos icon font; DrinkableTap a photo hero with a 200-weight 30px headline; Path a video background (use a still for 2011).
- **Content:** a 3-up feature row, "Sign up" and "Learn more", a short pricing table. Logo strips and "Customers" bands are period (Mailgun, Dec 2012). Custom art beats a generated screenshot or flat icons.
- **Mascot/character art** for a brand (MailChimp's Freddie, V-map).
- **Assets:** CSS3 buttons; sprites only for Glyphicons-style `icon-*` and the logo; a real screenshot in a `window` frame. No corner GIFs.

### (c) Textured personal blog or portfolio

- **Texture behind the page, reading area flat.** EJS (Aug 2011, Harmony CMS): one fixed background image on `html`/`body`, content on the open page, `-webkit-`/`-moz-` only, 4px radius and `rgba` backgrounds on `img`, letterpress on `body`.
- **Dark variant (Shawn Blanc, Oct 2011):** body `#393831`, text `#a0a08b` at 13px, headings `#bebea6` in `warnock-pro, Georgia, serif` at 22.75px, a repeating `background.jpg` over `#242320` on `#header`, `#navigation`, `.ancillary` only; no radius, no shadow.
- **Plain variants:** Marco.org (Oct 2011): flat `#372312` band, Georgia 16px, 620px column, breakpoints 680/520, no images, no CSS3. Twenty Eleven 1.2: body `#e2e2e2`, 15px Helvetica Neue 300, `#page` max 1000px, paired `-moz-`/`-webkit-box-shadow`, one `text-shadow`.
- **CMS fingerprints:** `.hentry`, `.entry-content` (WordPress); `.odd_posts`, `.archive_listing` (EJS); FancyZoom. [artifact] `<meta name="generator" content="WordPress 3.0.4">`, theme path `/wp-content/themes/<name>/`, Mint, ad pulls, `urchin.js`.
- **Type:** serif throughout, body 13–16px. Lobster over a Georgia body is the pastiche tell.
- **Tumblr sign-up (Nov 2011):** XHTML Transitional, Prototype, `#3c5a76` body with an image background, a 6px-radius image-backed "Start posting!" button. Tumblr blog themes (U).
- **Sharing:** none, `plusone.js`, or an Instapaper link.
- **Assets:** one `noise` or photo texture at the page edge; no sprites beyond the logo.

## 4. Costume mode: phones, fonts, basics

- **Phones, pick one and say which:** (1) fixed width the way Dribbble did it, `<meta name="viewport" content="width=1000">` (W = column + ~40); or (2) the period add-on: Bootstrap 2's `width=device-width` plus `bootstrap-responsive.css`-style `@media (max-width:767px)` rules that stack spans to 100%. Test at 375px either way: a fixed-width hero overflowed in a test build. Never disable zoom.
- **Fonts:** Typekit is now Adobe Fonts (`use.typekit.net`); use it if the owner has a kit. Otherwise self-host a WOFF via `@font-face` (period-correct mechanism) with an open face of the same class, or the system stack (Helvetica Neue / Georgia). Open stand-ins (not the period face: mark each with a `/* stand-in for proxima-nova */` comment and name it in the report): proxima-nova → Source Sans Pro (2012); ff-dax → PT Sans; ff-tisa → Merriweather; warnock-pro → Crimson Text. Keep the system fallback after it: `"Source Sans Pro", "Helvetica Neue", helvetica, arial, sans-serif`.
- **Libraries:** don't ship jQuery 1.x or Bootstrap 2 JS to production (known XSS issues in old versions). Use Bootstrap 2 CSS if wanted; write the collapse toggle and small effects in vanilla ES5 (`addEventListener` is period-fine here).
- **Social:** drop dead widgets (`plusone.js`, Instapaper iframe, the Like iframe); a plain text link if sharing matters. Today's Twitter `widgets.js` renders "X Post", so never use it.
- **Basics stay:** `alt` on images; image-replaced text keeps its real text (the `text-indent` pattern does); labels on inputs; readable contrast on textures and letterpress; HTTPS; UTF-8.

## 5. Tells (self-check)

- a fixed 630–960px column on a textured body; texture at the page edge, the reading area flat;
- 3–6px radius, `box-shadow`, patchy vendor prefixes (some rules full, some two, some bare);
- letterpress 1px shadows where text sits on grey; sprites and image replacement for logo, nav and download buttons;
- a flat screenshot with a drop shadow; Typekit-named families (or their stand-ins);
- head clutter (no-js, X-UA-Compatible, touch icons, OG tags); CMS or framework class names;
- on startups: grid classes `spanN`, custom header, real product shot, short pricing table.

## 6. Avoid

- **Too old:** tables for layout, `<font>`, corner GIFs and 1px-row corners, `-moz-border-radius` alone, a fixed 750px column, image-only gradient chrome on blogs and startups (app pages do use sprites), `urchin.js`.
- **Too new:** unprefixed-only `border-radius` or `linear-gradient`; flat fills with no shadows on app and startup pages; Font Awesome, Montserrat, Inter; `rem`; flexbox, grid, CSS variables, `prefers-color-scheme`; inline-SVG icon systems; a hamburger outside Bootstrap's `btn-navbar`; Bootstrap 3 classes (`col-md-*`, `navbar-default`); Bootstrap 2.3.2 on a 2012 page; Google-Fonts-only stacks where Typekit fits.
- **Allowed after all (seen on real pages):** an icon font (Sentry's Pictos, Dec 2012); a photo hero (Clear, DrinkableTap, Path video).
- **The cartoon:** a ribbon on every card; a phone with bezel and glare; a gel icon on a wooden desk; linen + leather + paper together; stitching; Lobster or a stamp logo on a Georgia body; gradient chrome on every element; the full prefix ladder everywhere; Like + Tweet on every post.

## 8. Skeleton

An app page (genre a), fixed `width=1000` phone policy. Startups swap the sheet for a custom `#header` and `spanN` rows.

```html
<!DOCTYPE html>
<html lang="en" class="no-js">
<head>
<meta charset="utf-8">
<meta http-equiv="X-UA-Compatible" content="IE=edge,chrome=1">
<meta name="viewport" content="width=1000">
<title>Tally - count anything from your menu bar</title>
<link rel="apple-touch-icon-precomposed" href="/img/icon-57.png">
<link rel="stylesheet" href="/css/screen.css?v=3">
</head>
<body>
<div id="header"><a href="/" class="logo replace">Tally</a><ul id="nav">...</ul></div>
<div id="main">
  <div id="featured"><h1>Count anything. One click.</h1><p>...</p><img src="/img/shot-main.png" width="..." height="..." alt="Tally's menu bar popover"></div>
  <div id="get"><a href="/download" class="btn">Download for Mac</a><p>$4.99 ...</p></div>
  <div id="features">...</div>
</div>
<div id="footer"><small>&copy; 2026 Tally Software</small></div>
</body>
</html>
```

```css
/* DEFINITIONS -- v1.2 */
*{margin:0;padding:0;border:0}
body{background:#e6e6e6 url(../img/bg-noise.png);font:13px/18px "Helvetica Neue",helvetica,arial,sans-serif;color:#333}
#header,#main{width:954px;margin:0 auto}
#main{background:#f4f4f2;-webkit-box-shadow:0 0 2px #666;box-shadow:0 0 2px #666}
.replace{display:block;overflow:hidden;text-indent:-999em;background:url(../img/sprite.png) no-repeat}
```
