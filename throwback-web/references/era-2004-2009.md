# Era 2: Web 2.0, 2004–2009

Build a page that passes as one from about 2006–2008.

Marks: **(V)** seen in a real archived capture or theme source; **(U)** unverified. **[artifact]** = artifact mode only; costume mode drops or replaces it as stated.

## 1. The two failures

1. **The cartoon:** glossy gel buttons, mirror reflections, "beta" starbursts, pastel everything. Six real 2006–2008 sites, including three 2008 startup pages, had no reflections, starbursts or beta badges; the period's own design guide called them overused in 2008. Allow at most one glossy element, typically a three-slice pill sign-up button (its gloss is U). "Beta" is plain text, in the title, or a small text label.
2. **Too tidy, too generic.** Real pages were template output (WordPress strings), raw user text with typos and ALL-CAPS (Digg), and mixes of new CSS with leftover tables (Flickr, Dropbox). Clean hand-written "Web 2.0" from scratch has none of that. Put in the genre's leftovers.

## 2. Shared rules

### Head

- XHTML 1.0 Transitional, standards mode (V in a browser: Digg 2006, a 2006 WordPress blog, RTM, Mint, Dropbox 2008). del.icio.us used Strict with `<html id="delicious">` and no xmlns. Never `<!DOCTYPE html>`.

  ```html
  <!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.0 Transitional//EN" "http://www.w3.org/TR/xhtml1/DTD/xhtml1-transitional.dtd">
  <html xmlns="http://www.w3.org/1999/xhtml">
  <meta http-equiv="Content-Type" content="text/html; charset=utf-8" />
  ```
  37signals used iso-8859-1 [artifact]. From 2008 `X-UA-Compatible` is plausible (Dropbox). No `<meta charset>`, no `device-width` viewport.
- Description/keywords meta optional (Flickr, 37signals yes; Digg no).
- Title: lowercase brand or slogan: "digg / News", "del.icio.us", "Twitter: What are you doing?", "WordPress › Blog".
- `<link rel="shortcut icon" href="/favicon.ico" type="image/x-icon" />`; RSS autodiscovery `<link rel="alternate" type="application/rss+xml" title="..." href="..." />`.
- CSS via `<link rel="stylesheet" type="text/css" media="screen" href="..." />` or `@import` inside `<style type="text/css" media="all">`, plus an inline `<style>` in the page (Dropbox, Kubrick). Rails cache-busters `?1167433714`.
- Scripts: a pile of `<script type="text/javascript" src="...">` in `<head>` (Digg ~10); inline code in `//<![CDATA[ ... //]]>`; no `async`/`defer`/modules.
- [artifact] `urchin.js` then `_uacct = "UA-xxxxx-x"; urchinTracker();` over `http://`. Costume: drop it (a default WordPress had none anyway).

### Markup

- `<div id="container|page|wrapper|header|content|sidebar|footer">`; nav as `<ul><li><a>`.
- Leftovers survive: Flickr 2007 nested layout tables; Dropbox 2008 an 800px table with `<center>`, `border="0"`, `valign`. Zero leftovers is too pure; the amount depends on genre.
- XHTML empties `<br />`, `<img ... alt="" />`. Validity not required (Dropbox doesn't validate).
- Inline styles and handlers per element are normal: `style="z-index:1000"` on each Digg story; `onclick="return(...)"` everywhere.
- Skip links, `accesskey`, microformats (`hentry`, `rel="bookmark"`, `rel="nofollow"`), real entities (`…`, `—`, `&amp;`).

### CSS

- **Width:** centred fixed column: Flickr 750, Twitter 755, Kubrick 760, RTM 765, MySpace/Dropbox 800, 37signals 840, Apple 980. Centre with `margin:0 auto` plus `body{text-align:center}` and `#container{text-align:left}`. Digg is fluid (genre below).
- **Columns:** two, at most three, floated, with a clearfix: `.clearfix:after{content:".";display:block;height:0;clear:both;visibility:hidden}` + `* html .clearfix{height:1%}`, or `<br class="clear" />`.
- **IE6 hacks visible:** `* html`, `/*IE6*/` comments, `!important /*imp for ie6*/`.
- **Gradients are images:** a tall image with `repeat-x`. Never a short strip tiled so bands repeat (a tell in a test build).
- **Rounded corners from images or markup:** stacked 1px `<b>`/`<div>` rows (RTM, Mint, Twitter `.xb1`–`.xb7`); corner GIFs (Dropbox `box-hl/hr/bl/br`); background images on nested divs (Digg). Four absolutely positioned corner divs on a flat box is a tell. `-moz-border-radius` only as a Firefox-only extra; never `border-radius`.
- **Buttons/tabs:** sliding doors and sprites, hover by `background-position`. A pill = three PNG slices with a `repeat-x` middle (RTM "Signup Now!").
- **Shadows:** `text-shadow` only as a Safari-only extra (Dropbox, in `rgba`). No `box-shadow`.

### Type and colour

- Base on `body` in % or em. Arial, Verdana, Lucida Grande, Tahoma or Trebuchet at 11–12px or 10pt; notes down to 8pt. Big headings `letter-spacing:-1px`.
- Links mostly underlined, a brand blue, a lighter visited colour. Flickr's reversed-colour hover block is Flickr's alone.
- Labels: "NEW" at 0.75em on `#FFCC66`, or an orange "New!" `#EA5200`; Flickr NEW in 8px Verdana on `#FFE28A`. Yellow notice boxes (`#ffffd0`), orange RSS button.

### JavaScript

- Libraries date the page: 2006 Prototype + script.aculo.us (Digg, Twitter, K2), Lightbox, swfobject, moo.fx; 2008 also MooTools (`window.addEvent('load', ...)`). jQuery 1.x plausible for 2008–09 (U, not seen).
- Inline handlers: `href="javascript://" onclick="return(fn())"`, `window.open('...','TOC','width=600,height=480')`.
- Inline AJAX for small actions (vote, save), Lightbox for images.
- [artifact] phpAds `document.write('<' + "script ...")` zones; `d.write` analytics; Flash video/demos via swfobject (Dropbox). Costume: drop ads; a poster image linking to the video replaces Flash.
- Placeholder text set by script (Facebook, Dropbox), not the `placeholder` attribute.

## 3. Genres

### Social news / bookmarking (Digg, del.icio.us, Dec 2006)

- **Fluid:** `html{min-width:902px}`, `#container{max-width:1200px}`, body padding `0 20px`. A rounded white content panel (image `main-back.gif`) on a pale body gradient.
- **Two nav bands:** brand band `#1B5790` with a sprite logo (hover state) and section buttons (News / Videos / Podcasts, with a text "beta"); below it a green sub-nav `#CCDEAF` ("All Topics / Technology / …") with a "Submit a New Story" pill on the right. A login drawer drops from the header. Tabs with counts: "Upcoming (3,455)".
- **Each story:** a yellow shaded count box ("30 diggs", text `#736926`) beside a separate vote box, each its own sprite (hover at `-300px`). Headline h3 130% bold, `letter-spacing:-0.02em`, underlined with a dotted image line; visited `#86b0e1`, hover `#003`. Red bold timestamp `#a12a2a`: "made popular 4 minutes ago". Toolbar: "N comments | Blog It | Email It | Topic: x" plus a Bury dropdown.
- **Palette** earthy: text `#393733`, green h2 `#8DAB3B` (185%, -1px), orange `#E45B00`, olive `#93883F`. Body `83%/1.4 arial`.
- **Copy:** raw user submissions with typos, ALL-CAPS words, odd casing.
- **Footer:** grey `#eee` strip of six `<dl>` columns with uppercase Tahoma links, a merch promo image, a trademark and Creative Commons paragraph.
- **del.icio.us instead:** XHTML Strict, `#ffffd0` notices, per item "people 130", "first posted by …" and five tags; a tag list on an `#eee` strip with size classes. Tag clouds belong to bookmarking, not to Digg.
- **Assets:** sprites for the logo (with hover), the count and vote boxes and the "Submit" pill; the content panel's round corners are background images on nested divs (or `corners` GIFs at the panel's four corners), not on each story.
- Invent your own vote verb and count label; never reuse "digg it".

### Blog on the WordPress Kubrick default theme (2006)

Template output is the fingerprint: copy the template strings exactly. Source: WordPress tag `2.0.5`, `wp-content/themes/default/` (research-method.md).

- **Head:** `<head profile="http://gmpg.org/xfn/11">`, then stylesheet, RSS alternate and pingback links in that order, then an inline `<style media="screen">` setting the `#page` background image. [artifact] `<meta name="generator" content="WordPress 2.0.5" />`; costume: drop it (it advertises a vulnerable version) unless the site really is that.
- **Post:**

  ```html
  <div class="post" id="post-N">
    <h2><a href="..." rel="bookmark" title="Permanent Link to TITLE">TITLE</a></h2>
    <small>November 9th, 2006 <!-- by author --></small>
    <div class="entry">...</div>
    <p class="postmetadata">Posted in <a>Cat</a> | <a>Edit</a> | <a>N Comments »</a></p>
  </div>
  ```
  Author only in the HTML comment. Dates always "Month Dayth, Year".
- **Sidebar order:** Search; "You are currently browsing…" paragraph; Pages; Archives; Categories; blogroll (each link category under its own `<h2>`); Meta (Register/Site Admin, Log in). No calendar; author blurb commented out.
- **Look:** body `#d5d6d7` with a 1px-wide JPG background; `#page` 760px, 1px `#959596` border, 20px margin; a background JPG draws the sidebar divider; header one 200px image (no `<img>`); footer image. Content 450px, sidebar 190px, 45px left padding. `hr{display:none}`. Links `#06c`, hover `#147`, visited `.entry p a` `#b85b5a`.
- **Details:** `.alt` comment striping (`#f8f8f8`, 1px `#ddd`); `abbr` dashed underline; `<span class="caps">` on acronyms; `» ` bullets on sidebar lists via `:before`.
- **Footer:** "Entries (RSS) and Comments (RSS)"; a query-count comment; theme credits. [artifact] `feed:` scheme links and Michael Heilemann's credit line; costume: `https` feed links, and credit only what you actually use.
- **Assets:** no corner GIFs or sprites; the header, page background and footer are single images.
- **K2 theme instead:** `hentry`, `entry-title`, `entry-meta`, `abbr.published` with an ISO title.

### Startup landing page, ~2008 (Remember The Milk, Mint, Dropbox)

- No sidebar: pitch, sign-up and proof in the centre column.
- **Assets:** `corners` GIFs on the one or two boxed panels (sign-up, tour), Dropbox `box-hl/hr/bl/br` style; the pill as three slices; a tall `gradient` behind the band. Not on every box.
- **RTM (Mar 2008):** full-width blue band `#005CB8` with a background PNG around a 765px column; a tilted, stylised product graphic (not a screenshot) overlapping the band by 12px; a three-slice "Signup Now!" pill, then "for a free account" and "take a tour"; a 3×2 `<table>` of captioned feature images; a press quote with the publication logo; a six-column footer link list and a legal line.
- **Mint (Apr 2008):** plain-text headings ("Free Personal Finance Software"); "Learn More" and "Sign Up Now"; a tabbed tour; rotating testimonials with full name and city; trust seals in the footer; MooTools.
- **Dropbox (Jun 2008, beta):** 800px table with `<center>`; a demo video; a beta email sign-up with script-set placeholder text; "beta" in title and copy; a right-aligned 8pt footer row; Tahoma/Trebuchet 10pt.

### Photo, community, app (first research pass only, no test build)

- **Flickr 2006–07:** 750px with nested tables; a 424×283 hero photo with "Sign Up Now!"; links `#0063DC` with a reversed hover; NEW label as above.
- **37signals:** 840px, Verdana 12px with Georgia intros, a cream band `#fff9d8`, black footer with 10px text.
- **Twitter 2007–08:** 755px, Lucida Grande .75em, a 555+166 split, `#DDFFCC` sidebar, a "beta" label, image-free rounded corners from 1px rows.
- **MySpace 2006:** 800px, Verdana 11px, `#039` header, `Home | Browse | Search | …` pipe nav.

## 4. Costume mode: phones and basics

- **Phones:** keep the fixed column. Add `<meta name="viewport" content="width=W" />`, W = column width + 40 (Digg-fluid: the `min-width`, 902). Invisible on desktop; the phone opens fitted to the column. Never disable zoom. Keep body type at 11px or larger so it survives the zoom-out.
- **Basics stay:** `alt` on images, `<label for>` on every control (alongside any script-set placeholder text), keyboard-reachable vote/tab controls (real `<a href>` or `<button>`, not bare `onclick` on a `<div>`), readable contrast, HTTPS, UTF-8.
- **Libraries:** don't ship Prototype/MooTools/old jQuery for flavour (unmaintained, known issues). Write the few behaviours in ES3-style vanilla JS with inline handlers; it reads period-correct.
- **Drop:** `urchin.js`, ad `document.write`, Flash, `http://` assets, the WordPress generator meta, `feed:` links, stale ©.

## 5. Tells (self-check)

- XHTML 1.0 doctype, `xmlns`, http-equiv charset, favicon and RSS links, scripts piled in `<head>`;
- a 750–840px centred column (or Digg's min/max fluid) on a pale grey or image-gradient canvas;
- brand-colour header band, often a second sub-nav band; floats + clearfix + an IE6 hack; one table leftover;
- corners and gradients from images, sprites with `background-position` hovers;
- underlined brand-blue links; 11–12px Arial/Verdana/Lucida Grande/Tahoma; headings at -1px;
- genre content: counts, "submitted by", timestamps, tags; or WordPress strings; or a pitch with a pill button, a feature table, named testimonials and seals;
- footer: `<dl>` link columns or a short pipe row, a © line, blog "powered by" credits.

## 6. Avoid

- **Too old:** `<font>`, `bgcolor` everywhere, spacer-GIF layouts, image-map nav, no doctype, a link-wall homepage.
- **Too new:** flexbox, grid, `@media` width queries; `border-radius`, `box-shadow`, CSS gradients, `rgba` outside a Safari-only `text-shadow`, `@font-face`; Google Fonts, icon fonts, SVG; HTML5 elements, `<meta charset>`, `data-` and `placeholder` attributes; `addEventListener`, ES6, `fetch`, jQuery 2+, `gtag`.
- **The cartoon:** reflections, starbursts, "beta" badge graphics, more than one glossy element, pastel everything.
- **Too tidy:** edited uniform copy where real sites had user text or template strings; no leftovers and no hacks.

## 8. Skeleton

Head plus a fixed centred column with a two-column float body. Genre sections set the width and the bands.

```html
<!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.0 Transitional//EN" "http://www.w3.org/TR/xhtml1/DTD/xhtml1-transitional.dtd">
<html xmlns="http://www.w3.org/1999/xhtml">
<head>
<meta http-equiv="Content-Type" content="text/html; charset=utf-8" />
<meta name="viewport" content="width=800" />
<title>potluck / recipes</title>
<link rel="shortcut icon" href="/favicon.ico" type="image/x-icon" />
<link rel="alternate" type="application/rss+xml" title="potluck - popular" href="/rss/popular.xml" />
<link rel="stylesheet" type="text/css" media="screen" href="/css/style.css?1167433714" />
<script type="text/javascript" src="/js/site.js"></script>
</head>
<body>
<div id="container">
  <div id="header"><a href="/" id="logo">potluck</a><ul id="nav"><li><a href="/">Popular</a></li>...</ul></div>
  <div id="content" class="clearfix">
    <div id="main">...</div>
    <div id="sidebar">...</div>
  </div>
  <div id="footer">...<p>&copy; 2026 Potluck</p></div>
</div>
</body>
</html>
```

```css
body{margin:0;background:#e8e8e8 url(../img/bg.png) repeat-x;font:76%/1.4 verdana,geneva,"DejaVu Sans",sans-serif;text-align:center}
#container{width:760px;margin:0 auto;text-align:left;background:#fff}
#main{float:left;width:530px}  #sidebar{float:right;width:200px}
.clearfix:after{content:".";display:block;height:0;clear:both;visibility:hidden}
* html .clearfix{height:1%} /* IE6 */
```
